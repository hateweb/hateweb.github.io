What is Wintamins?

It is a lightweight tool designed to improve your Windows workflow by allowing you to drag, resize, maximize, minimize or close any window by pressing a shortcut, while having your cursor on the window.

For healthy window management

Wintamins brings something that Windows lacks, but other operating systems like macOS and Linux have had for decades, fixing an important aspect of the computing experience.

And how does it compare to other similar tools?

Ours is more lightweight, more optimized, and is in active development. We're constantly working on the project to improve the user experience. Give it a try!
